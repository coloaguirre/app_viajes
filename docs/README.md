  (`DISENO.md`) y el README del paquete de arranque original. INMUTABLES
  para el agente: son la base del plan de trabajo. Versiones nuevas
  entran como archivo nuevo (`DISENO-v2.md`), nunca pisando el anterior.

  en la calle.
- `PROGRESS.md` — registro de avance por fase (lo mantiene Claude Code).
