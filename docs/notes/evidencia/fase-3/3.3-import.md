# Evidencia ítem 3.3 — importación de `trip.json` y de GPX externo (2026-10-13)

## Qué hace
- Desde Mis viajes, el botón "+" abre el selector de archivos del sistema (ZIP del
  paquete, `trip.json` suelto o GPX de otra app). `ImportWorker` (WorkManager)
  detecta el tipo por el nombre, lee el archivo por su URI y guarda todo en Room en
  una sola transacción (`TrackingRepository.importTrip`).
- ZIP: primera pasada para leer `trip.json`; si el viaje ya existe, el diálogo
  pregunta **Reemplazar** (borra el existente, cascada incluida) o **Importar como
  copia** (todos los ids se regeneran de forma consistente). Segunda pasada: las
  fotos y videos se copian a `Pictures/BitacoraViaje/<viaje>/` (y `Movies/…`) vía
  MediaStore con su id de MediaStore guardado en el ítem, para que el siguiente
  barrido reconozca las copias y no las vuelva a vincular como fotos nuevas; los
  audios van a los archivos de la app con la ruta que espera la nota.
- GPX externo: cada `<trk>` es una etapa (tipo según `<type>`: hiking/walking → a
  pie, cycling → bici, driving → auto…), cada `<trkseg>` una pausa, cada `<wpt>` un
  lugar marcado; estadísticas y paradas se recalculan con `core/geo`. Un GPX sin
  `<time>` recibe horas ficticias de 1 s y un aviso (sin horas reales no se pueden
  vincular fotos). Parser SAX: el mismo código corre en la JVM y en Android.
- `trip.json` de una `schema_version` distinta se rechaza con un mensaje claro.

## Tests (150 verdes en la puerta local)
- `ImportRoundTripTest` (aceptación del PLAN, Robolectric + Room): un viaje con
  puntos, pausa, parada detectada, foto, nota de voz y marcador se exporta a
  `trip.json`, se importa como copia y la base de la copia tiene exactamente el mismo
  contenido (huella por entidad, sin ids ni URIs); reemplazar el original con el mismo
  archivo deja una sola copia con el mismo contenido.
- `ImportTest` (`core/export`): ida y vuelta JSON con todos los campos; ids
  regenerados consistentes; versión de esquema incorrecta y basura rechazadas; ida y
  vuelta GPX (puntos, dos `trkseg` → dos pausas, 8 waypoints → marcadores, medio
  "auto" desde `<type>`); GPX sin horas; el GPX de `tools/sample-trips/trekking` carga.

## E2E en el emulador
Mis viajes → "+" → selector del sistema → `Viaje_2026-10-12.zip` (el exportado en
3.2) → "El viaje ya está en el teléfono" (`3.3-import-conflicto.png`) → "Importar
como copia" → "Viaje importado" → "Abrir el viaje": la copia muestra su línea de
tiempo (`3.3-import-copia.png`) y la grilla de fotos. Base: dos viajes, 6 de 6
fotos de la copia con URI y id de MediaStore, 4 notas de voz (2 + 2), 169 puntos.
El barrido de fotos posterior reconoció las copias (`scanned=12 linked=3 skipped=9`)
sin duplicar nada; antes de guardar el id de MediaStore sí las duplicaba (corregido).
