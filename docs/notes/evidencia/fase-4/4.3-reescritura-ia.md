# Evidencia ítem 4.3 — reescritura opcional con un modelo de lenguaje (2026-10-13)

## Qué hace
- **Desactivada por defecto y sin clave no aparece.** En Ajustes, sección "Reescritura
  con IA (opcional)": campo de clave de la API de Claude (se escribe oculto, nunca se
  vuelve a mostrar; solo "Clave guardada" / "Sin clave", con Borrar) y el modelo
  (`claude-sonnet-5` por defecto, editable). La clave se guarda con `KeystoreSecretStore`:
  AES-GCM con una clave del Android Keystore, texto cifrado (IV + datos) en
  `files/secrets/`, carpeta que las reglas de respaldo no incluyen; nunca se loguea ni
  viaja en exportaciones (`trip.json` no la conoce).
- Con clave, cada texto de **Wikipedia** de la pestaña Lugares ofrece **Reescribir con
  IA** (los datos de Wikidata son literales y no se reescriben). `ClaudeRewriter` llama a
  la Messages API con un cliente HTTP propio (sin caché ni interceptores compartidos):
  en el cuerpo van solo el nombre del lugar, el `extract` de Wikipedia y las líneas de
  Wikidata; nunca coordenadas, fotos ni notas. El *prompt* exige usar exclusivamente el
  texto fuente y responder `SIN_DATOS` si no hay nada que contar.
- **Validación** (`RewriteGuard`, puro): se descarta la respuesta si trae un número que
  no está en la fuente ni en los datos (separadores de miles normalizados), si supera
  70 palabras o si es el centinela. Si se descarta, se conserva el texto original y la
  pestaña lo informa. Una clave rechazada (401/403) o un error del servicio se muestran
  como mensaje, sin tocar el texto.
- El texto reescrito reemplaza `summary`, el original pasa a `original_summary`
  (**esquema v8**) y `llm_rewritten = 1`; la fuente, la URL y la licencia se conservan
  siempre y la tarjeta lo marca ("Texto reescrito"). **Restaurar original** vuelve al
  texto de la fuente. Lo mismo vale para la edición manual (el original se guarda una
  sola vez). Al volver a enriquecer, un texto aprobado, editado o reescrito no se pisa:
  el nuevo texto de la fuente queda como "original" para restaurar.
- `trip.json` lleva `original_text`, `llm_rewritten` y `user_approved` por texto; la
  atribución a Wikipedia se mantiene aunque el texto esté reescrito (DISENO §11.4).

## Tests
- `LlmRewriterTest`: extracción de números (3.406 → 3406, 2,5 → 2.5), fidelidad
  (un año inventado se rechaza), centinela y largo máximo; con MockWebServer: la
  petición lleva `x-api-key`, `anthropic-version`, el modelo, el texto fuente y los datos,
  y ninguna coordenada; una cifra inventada (5.000) devuelve nulo; 401 lanza
  `LlmAuthException`; 529 propaga el mensaje del servicio.
- `DetailScreensComposeTest`: sin clave no existe el botón de reescritura ni el de
  restaurar; con clave y texto reescrito aparecen ambos, con la marca "Texto reescrito",
  y emiten `Rewrite` / `Restore`.
- `PlacesRepositoryTest` (refresco conserva aprobación y texto), `MigrationTest` 7→8,
  `UserSettingsTest` (modelo válido/inválido).
