# Evidencia ítems 0.1 y 0.3 — entorno y app en el emulador (2026-10-12)

## 0.1 Entorno
```
$ ./tools/setup-linux.sh --check   -> Entorno completo (exit 0)
$ adb devices
List of devices attached
emulator-5554	device
$ java -version   -> openjdk version "17.0.20.1" 2026-08-18
$ ffmpeg -version -> ffmpeg version 7.0.2-static
```
Emulador `bitacora36` (android-36 google_apis x86_64, 2 GB RAM) arrancado
headless con KVM: `emulator -avd bitacora36 -no-window -no-audio -no-boot-anim
-gpu swiftshader_indirect -memory 2048`. Arranque completo en 90 s.
Nota: el proceso de Claude Code no hereda el grupo `kvm` nuevo; se lanza
con `sg kvm -c "emulator ..."`. Verificación de SDK 37: existe (37.0,
37.1, 37.2); se compila contra 37.0 (ver PROGRESS).

## 0.3 La app abre
```
$ adb install -r app/build/outputs/apk/debug/app-debug.apk -> Success
$ adb shell am start -W -n com.bitacoraviaje.app/.MainActivity -> Status: ok, TotalTime ~6-9 s (primer arranque, debug)
$ adb logcat -d -s AndroidRuntime:E | grep -c FATAL -> 0
```
