# Adenda 1 al pedido original

> Transcripción literal de los cambios que el usuario pidió el 2026-10-11,
> antes del kickoff, tras ver la comparativa con Polarsteps y la explicación
> del registro en segundo plano. Documento fuente: no se edita.

Antes de empezar, algunos cambios:

- El user inicia el viaje, pero el viaje no termina hasta que el user lo
  declara. No hace falta que cada día lo inicie.
- Dos opciones de registro / consumo de batería a decisión del user: full
  (como está planeado) o económico (en situaciones de trekkings largos sin
  posibilidad de recarga).
- Me gustó el minivideo de 1 minuto a demanda.
